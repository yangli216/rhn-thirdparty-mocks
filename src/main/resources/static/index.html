场景速查（按输入值触发，无需改配置）

MOB/CHS · 证件号（identityNumber）

  • TEST-390 单条费用明细
  • TEST-MULTI 多条明细
  • TEST-SUSPENDED 参保人暂停
  • TEST-NOINSU 无参保信息
  • TEST-REJECT-2206 结算拒绝 2206
  • TEST-IMBALANCE 明细合计不符
  • TEST-MISSING-AMT 缺少金额
  • TEST-SLOW 慢响应
  • TEST-HTTP500 HTTP 500
  • TEST-BADJSON 非 JSON 正文
  • TEST-SIGN-EXPIRE 登录态失效
  • 其它任意值 → NORMAL

支付宝 · 请求值钩子

  • auth_code 前缀 SIM_PAYING_ → 10003 处理中
  • auth_code 前缀 SIM_FAIL_ → 40004 失败
  • out_trade_no 后缀 -CLOSED → 交易已关闭

微信 · 单号后缀钩子

  • out_trade_no 后缀 -CLOSED 已关闭
  • out_trade_no 后缀 -REVOKED 已撤销
  • out_trade_no 后缀 -PAYERROR 支付失败

CA · 证件号（identityNumber）

  • TEST-REVIEW 待审核
  • TEST-REJECT 备案被拒
  • TEST-CERT-PENDING 证书待下发
  • TEST-DISABLED 账号停用
  • TEST-CERT-EXPIRED 证书已过期
  • TEST-REVOKED 证书已吊销
  • TEST-SIGN-FAIL 签名失败
  • TEST-SIGN-REJECT 拒签
  • TEST-BAD-SIGNATURE 签名值损坏
  • TEST-BAD-ENVELOPE 内嵌摘要不符
  • TEST-VERIFY-FAIL 验签不通过
  • TEST-SLOW / TEST-TIMEOUT / TEST-HTTP500 / TEST-BADJSON
